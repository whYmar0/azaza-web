# ADR-002: Черновик (5 строк)

Фоновые задачи — вероятно, in-memory (поток + словарь), а не Celery/Redis,
чтобы не тащить лишнюю инфраструктуру. Причина:
генерация судоку с проверкой единственности решения может занимать
секунды, значит нужен паттерн 202 + опрос статуса. Риск: состояние
задач теряется при перезапуске процесса — пересмотреть, если понадобится
несколько воркеров. Решение будет дописано подробнее позже.
