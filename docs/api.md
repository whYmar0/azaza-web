# API

Живая интерактивная документация (Swagger, автогенерация Django Ninja) —
`/api/docs`, доступна сразу после `python manage.py runserver`. Ниже —
письменная копия того же контракта.

Источник истины — `core.schemas.SudokuParams`: и форма (`web/forms.py`), и
API (`web/api.py`) получают одни и те же поля из одной схемы, поэтому они
не могут разойтись по именам.

## `POST /api/tasks`

Создаёт задачу (решить готовую сетку или сгенерировать новую) и
возвращает её id. Расчёт выполняется в фоне.

**Тело запроса:**
```json
{
  "name": "сетка №14",
  "params": {
    "mode": "solve",
    "grid": "53..7....6..195....98....6.8...6...34..8.3..17...2...6.6....28....419..5....8..79",
    "difficulty": "medium",
    "seed": null
  }
}
```

`grid` обязателен при `mode="solve"`, не нужен при `mode="generate"`
(вместо него — `difficulty`/`seed`).

**Ответ:** `202 Accepted`
```json
{"id": 1}
```

**Ошибка валидации** (например, `grid` не 81 символ, или `mode` не
`solve`/`generate`) — `422`, текст ошибки указывает конкретное поле:
```json
{"detail": [{"type": "string_too_short", "loc": ["body", "payload", "params", "grid"],
             "msg": "String should have at least 81 characters"}]}
```

## `GET /api/tasks/{id}`

Статус задачи.

**Ответ:** `200`
```json
{"id": 1, "name": "сетка №14", "status": "done", "error": ""}
```

`status` — одно из `queued` / `running` / `done` / `error`. При `error`
поле `error` содержит причину (например, для `mode="generate"` — «Генератор
ещё не реализован»).

## `GET /api/tasks/{id}/result`

Результат — только когда `status == "done"` (иначе `404`).

**Ответ:** `200`
```json
{
  "puzzle": "53..7....6..195....98....6.8...6...34..8.3..17...2...6.6....28....419..5....8..79",
  "solution": "534678912672195348198342567859761423426853791713924856961537284287419635345286179",
  "clues": 30,
  "elapsed_ms": 0.0
}
```

## Проверено вживую

Все четыре сценария прогнаны через `curl` (не только через `/api/docs`):
`solve` с валидной сеткой → `202` → `done` → результат; `generate` → `202`
(принято, расчёт пока не реализован); сетка из 80 символов → `422` с
текстом ошибки в поле `grid`.
