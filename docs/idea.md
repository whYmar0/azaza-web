# Идея проекта: Sudoku Service

## Идея одной фразой

Веб-сервис для судоку с единым контрактом на два входа: страница для
человека и `POST /api/tasks` для программы. Одна и та же задача, заданная
через `core.schemas.SudokuParams` (`mode`, `grid`, `difficulty`, `seed`),
либо **решает** готовую сетку с гарантией через доказанно единственный
ответ, либо (следующий шаг) **генерирует** новую головоломку с гарантией
единственного решения.

## Проверка тремя вопросами

1. **Что пользователь вводит?** Строка из 81 символа (`1`-`9` и `.` для
   пустой клетки) — либо параметры генерации (`difficulty`, `seed`).
2. **Какая функция долго думает?** `core/solver.py` — backtracking с
   MRV-эвристикой, ищет не одно, а до двух решений подряд, чтобы отличить
   «решение единственно» от «решений много». Для сложных головоломок
   (мало подсказок) перебор занимает заметное время — асинхронно, через
   `POST /api/tasks` → `202` → опрос статуса → `GET .../result`.
3. **Что получается на выходе?** Либо решённая сетка (81 символ), либо
   `"multiple"`/`"no solution"`, если решение не единственно.

## Почему это проходит рамку

Сервис не сводится к «просто каталогу» — в основе вычислительно тяжёлая
задача (доказательство единственности решения перебором), из-за которой
генерация для сложных головоломок выполняется в фоне, а не мгновенно.

## Текущее состояние (реализовано)

- `core/solver.py` — решает готовую сетку, отличает единственное решение
  от неоднозначного (проверено на двух независимых эталонах: головоломка
  с Wikipedia и «самая сложная судоку в мире», Arto Inkala, 2012).
- `core/schemas.py` — валидация входа до расчёта (структура + отсутствие
  дублей цифр в строках/столбцах/блоках).
- `web/api.py`, `web/services.py` — API поверх ядра, задача выполняется в
  фоне, статус хранится в модели `Task`.

## Пока не реализовано

- `core/generator.py` — генерация новой головоломки. `mode="generate"`
  в API уже принимается (`202`), но задача завершается статусом `error`
  с понятным сообщением — честно, без притворства, что расчёт прошёл.
