# Идея проекта: Sudoku Generator & Solver

## Идея одной фразой

Веб-сервис-генератор судоку с гарантией единственного решения: пользователь
выбирает уровень сложности, а программа не просто заполняет сетку по
правилам, но и проверяет, что после удаления клеток у головоломки остаётся
ровно одно решение — не ноль и не несколько. Дополнительно сервис умеет
решать и проверять произвольные чужие сетки судоку.

## Проверка тремя вопросами

1. **Что пользователь вводит?** Уровень сложности (easy / medium / hard) —
   либо готовую сетку 9×9 для решения или проверки.
2. **Какая функция долго думает?** Составление судоку — это, по сути,
   решение пустой сетки по правилам (в каждой строке, столбце и блоке 3×3 —
   цифры 1–9 без повторов). При удалении клеток запускается перебор,
   проверяющий, что решение остаётся единственным. Для hard-уровня, где
   подсказок минимум, этот перебор считает секунды, а не миллисекунды.
3. **Что получается на выходе?** Готовая головоломка, полное решение и
   время выполнения — либо результат находится быстро благодаря
   оптимизированному алгоритму, либо на глазах пользователя постепенно
   улучшается с каждой итерацией, пока не станет верным.
